## Project Overview
This repository contains the automated test scripts for Assignment 1 (Option 1) of the IT3040 module. It uses Python and Playwright to evaluate the transliteration accuracy of the Pixelssuite Chat Translator by testing 50 negative scenarios.

## Prerequisites
Before running this project, ensure you have the following installed on your machine:
* Python 3.11 or 3.12
* Google Chrome

## Setup and Installation
Follow these steps to set up the project environment:

1. Clone this repository or extract the project zip file.
2. Open a Command Prompt (cmd) or Terminal and navigate to the project directory (`test_automation`).
